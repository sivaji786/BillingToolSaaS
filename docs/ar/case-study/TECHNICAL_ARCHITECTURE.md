# الهندسة التقنية: BillingTool

## نظرة عامة على النظام

تم بناء BillingTool على هندسة حديثة وقابلة للتوسع تفصل بين طبقة العرض (الواجهة الأمامية) وطبقة واجهة برمجة التطبيقات (الواجهة الخلفية)، مما يضمن سهولة الصيانة والأمان والأداء العالي.

## الهندسة رفيعة المستوى

ينقسم النظام إلى أربع طبقات رئيسية:
1. **طبقة العميل**: متصفح الويب مع تطبيق React 18.
2. **طبقة الواجهة الأمامية**: مكونات TypeScript، تسيق Tailwind CSS، وإدارة الحالة.
3. **طبقة الواجهة الخلفية**: API مبني بـ CodeIgniter 4 مع مصادقة JWT ومنطق أعمال يعتمد على Traits.
4. **طبقة البيانات**: قاعدة بيانات MySQL مع مخطط متعدد المستأجرين.

## هندسة SaaS وتعدد المستأجرين

### العزل القائم على النطاقات الفرعية
يستخدم النظام توجيهاً ديناميكياً للنطاقات الفرعية حيث يصل كل مستأجر عبر `{tenant}.humpl.org`.

- **تحديد المستأجر**: يقوم `TenantFilter` بالتحقق من النطاق الفرعي مقابل قاعدة البيانات.
- **الأمان المغلق عند الفشل**: في حالة عدم وجود مستأجر صالح، يتم حظر الوصول إلى جميع البيانات تلقائياً.

### منطق الوحدات المعتمد على Traits
يتم تغليف منطق SaaS الأساسي فيTraits PHP قابلة لإعادة الاستخدام:
- **TenantScope**: عزل البيانات العالمي من خلال حقن `tenant_id` تلقائياً في الاستعلامات.
- **UsageEnforcement**: فرض حدود الخطة (الفواتير، المستخدمين).
- **AuditTrait**: تسجيل جميع التغييرات لضمان سجل تدقيق قابل للبحث.

## هندسة الواجهة الأمامية

- **الإطار**: React 18.3.1
- **اللغة**: TypeScript
- **التنسيق**: Tailwind CSS 4.0
- **أداة البناء**: Vite
- **المكونات**: shadcn/ui و Lucide React للرموز.
- **الرسوم البيانية**: Recharts لتصور البيانات.

## هندسة الواجهة الخلفية

- **الإطار**: CodeIgniter 4.x
- **اللغة**: PHP 8.1+
- **قاعدة البيانات**: MySQL 8.0+
- **المصادقة**: JWT (JSON Web Tokens)
- **الذكاء الاصطناعي**: تكامل Gemini API للميزات الذكية.

## بنية الأمان

- **المصادقة**: أمان يعتمد على رموز JWT.
- **التفويض**: التحكم في الوصول القائم على الأدوار (RBAC).
- **حماية البيانات**: استخدام الاستعلامات المجهزة، منع XSS، وتشفير الاتصالات عبر HTTPS.

## بنية النشر

- **الاستضافة المشتركة**: نشر كلاسيكي PHP/MySQL.
- **VPS/Cloud**: خادم مخصص مع Nginx/Apache.
- **Docker**: نشر حاويات لسهولة التوسع.
