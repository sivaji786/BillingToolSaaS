# تقرير وحدة: نظام الفوترة والاشتراكات
**الحالة:** 🟡 قيد التطوير

## 1. الوحدات الفرعية
- **مدير الخطط:** إدارة مستويات الاشتراك (Starter، Pro، Enterprise).
- **متتبع الاستخدام:** مراقبة استدعاءات API والتخزين.
- **بوابة الدفع:** تكامل مزود خارجي (Stripe).

## 2. الوظائف والحالة
| الوظيفة | الوصف | الحالة |
|---------|-------|--------|
| **تعريف المستويات** | البيانات الوصفية للسعر والميزات والحدود | ✅ مستقر |
| **خطة QuickAccess** | تعيين تلقائي لخطة "تتبعية" للمستخدمين الجدد | ✅ مستقر |
| **الاستخدام الفوري** | أدوات وفرض الحدود (التخزين، API) | ✅ مستقر |
| **الفوترة التلقائية** | تجديد الاشتراك عبر Webhooks | 🟡 جارٍ |
| **تنبيهات الحد** | إشعارات بريد عند 80%، 90%، 100% | ✅ مستقر |

## 3. الخارطة الزمنية
- التكامل مع PayPal وبوابات الدفع المحلية.
- دعم رموز الخصم والقسائم الترويجية.
