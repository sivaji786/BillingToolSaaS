# تقرير وحدة: المصادقة والتحكم في الوصول القائم على الدور
**الحالة:** 🟡 مستقر (في تطوير)

## 1. الوحدات الفرعية
- **فلتر المصادقة الهجينة:** مصادقة موحدة لـ API (JWT) والويب (الجلسة).
- **محرك RBAC:** فحوصات دقيقة للأذونات (`RbacFilter.php`).
- **مزود الهوية:** إصدار وتحقق الرموز القائمة على JWT.

## 2. الوظائف والحالة
| الوظيفة | الوصف | الحالة |
|---------|-------|--------|
| **تسجيل دخول JWT** | مصادقة عديمة الحالة للعملاء | ✅ مستقر |
| **التبديل SA/عميل** | منطق للأدوار المتعددة عبر البوابات | 🟡 في تطوير |
| **صلاحيات الموارد** | تعريف صلاحيات مثل `invoices.create` | 🟢 نشط |
| **قائمة إلغاء الجلسة** | إلغاء الرموز من جانب الخادم | 🔴 معلق |

## 3. الخارطة الزمنية
- تنفيذ المصادقة متعددة العوامل (MFA).
- إضافة دعم تسجيل الدخول الاجتماعي (Google/GitHub).
