# وحدة مساحة العمل (مساحة عملي)

توفر وحدة مساحة العمل نظام إدارة ملفات متعدد المستأجرين يتيح للمستخدمين رفع وتنظيم والبحث في الوثائق المتعلقة بالمشاريع.

## 1. نظرة عامة تقنية

- **مكون الواجهة الأمامية**: `src/components/screens/Workspace.tsx`
- **كنترولر الواجهة الخلفية**: `App\Controllers\WorkspaceController`
- **نموذج قاعدة البيانات**: `App\Models\WorkspaceFileModel`
- **مسار التخزين**: `WRITEPATH/uploads/tenants/{tenant_id}/workspace/`

## 2. الوظائف الأساسية

### 2.1 إدارة الملفات
- **عمليات CRUD**: يمكن للمستخدمين إنشاء المجلدات ورفع الملفات وإعادة تسمية العناصر وحذفها.
- **حدود الرفع**: مُفرضة على مستوى الخادم.
- **الأمان**: تطهير المسار يمنع هجمات اجتياز الدليل.

### 2.2 دعم ZIP
- **الاستخراج**: دعم استخراج أرشيفات `.zip` مباشرةً داخل مساحة العمل.
- **التنزيل الجماعي**: تحديد عناصر متعددة وتنزيلها كملف ZIP واحد.

### 2.3 البحث بالذكاء الاصطناعي (مدعوم بـ Gemini)
1.  **اللغة الطبيعية إلى SQL**: يستخدم النظام Gemini لتحويل الاستعلام النصي إلى جملة SQL.
2.  **التصفية السياقية**: SQL المُولَّد مقيد بـ `tenant_id` الخاص بمساحة العمل.
3.  **ذاكرة التخزين المؤقت**: الاستعلامات المتكررة مخزنة في جدول `aiquery_history`.

## 3. التعددية في المستأجرين والأمان

### 3.1 عزل البيانات
1.  **نظام الملفات**: لكل مستأجر مجلد مخصص.
2.  **قاعدة البيانات**: `WorkspaceFileModel` يمتد `BaseModel` باستخدام سمة `TenantScope`.

## 4. مفاتيح تتبع الاستخدام
- **storage_gb**: الحجم الإجمالي لجميع الملفات في مساحة عمل المستأجر.
- **api_calls**: طلبات البحث بالذكاء الاصطناعي تستهلك رصيد استدعاءات API.
