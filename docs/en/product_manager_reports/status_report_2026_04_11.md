## 4. Key Achievements (Apr 6–11, 2026)

### 🔐 Auth Hardening
- **Password Reset**: Full end-to-end forgot password flow — email submission, token-based link, secure reset screen with show/hide toggle, minimum length validation.
- **DB Migration**: `password_resets` table (email, token, created_at) created via dedicated migration.
- **Public Route**: `UnifiedAuthFilter` now excludes `/reset-password` so unauthenticated users can land on the reset screen without being redirected.

### 🧾 Invoice Intelligence
- **Configurable Number Format**: Tenants can define their invoice numbering pattern using variables `{YYYY}`, `{YY}`, `{NNN...}` (padding by N count). Default: `INV-{YYYY}-{NNNNN}`.
- **Invoice Defaults**: Company profile now stores `default_currency` (EUR), `default_tax_rate` (19.00%), and `payment_terms_days` (30). New invoices inherit these automatically.
- **Auto-Numbering Utility**: `generateInvoiceNumber(format, currentCount)` added to `invoice-calculations.ts` — replaces manual numbering across the invoice pipeline.

### 🛒 Buyers Management
- Column sorting (name, email, company, address) with asc/desc toggle and directional icons.
- Client-side address filter for quick lookup in large buyer directories.

### ⚙️ Settings UX
- New "Invoice Defaults" section in Settings: fields for Default Currency, Default Tax Rate (%), Invoice Number Format (with variable hint), and Payment Terms (days).

### 🌐 Translations
- New keys added across EN, DE, AR for template validation (`nameRequired`, `sellerNameRequired`, `uploadImageError`, `imageSizeError`, `logoUploadSuccess`, `logoUploadError`), design layout label, and signup screen improvements.
