## 📊 Project Overview

**BillingTool** is a comprehensive multi-tenant SaaS invoice management system featuring:

- ✅ **SaaS & Multi-Tenancy** - Subdomain-based isolation and fail-closed security
- ✅ **EN 16931 Compliance** - European e-invoicing standard with real-time validation
- ✅ **Usage Enforcement** - Hard limits based on SaaS plan tiers
- ✅ **Gemini AI Integration** - Smart invoice drafting, analysis, and compliance advice
- ✅ **My Workspace** - Personal productivity hub with plan-gated access
- ✅ **Quick Access** - Zero-friction trial provisioning via auto-assigned trailing plan
- ✅ **Quick Tour** - Guided onboarding walkthrough for new users
- ✅ **Buyers / Contacts** - Persistent contact book with invoice auto-fill
- ✅ **Super Admin Portal** - Full platform oversight (tenants, plans, billing, tickets, analytics)
- ✅ **Ticketing Widget** - Embedded support ticket widget on every page
- ✅ **Admin Wiki** - Live in-portal documentation viewer for Super Admins
- 📊 **Unified Dashboard** - Financial insights + Activity timeline
- 📜 **Centralized Auditing** - Complete audit trail via `AuditTrait`
- 🌍 **Multilingual Support** - 6 languages with RTL support
- 📤 **Multi-Format Export** - PDF, UBL XML, JSON, CSV
- 🚀 **Modern Tech Stack** - React 18, TypeScript, CodeIgniter 4

## 🏗️ Technology Stack

**Frontend:** React 18 + TypeScript + Tailwind CSS v4.0  
**Backend:** CodeIgniter 4 + PHP 8.1+  
**Standards:** EN 16931, UBL 2.1, WCAG 2.1 AA
