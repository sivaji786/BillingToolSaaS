# Sales: Enterprise Onboarding Guide

This guide outlines the process for sales representatives and account managers to facilitate the onboarding of high-value enterprise clients.

## 1. Custom Package Creation
For enterprise deals that don't fit into the standard **Starter** or **Pro** buckets:
1.  **Request Access**: Ensure you have Super Admin permissions.
2.  **Define Limits**: Use "Packages" > "Create New". Set visibility to **Private**.
3.  **Tailor Limits**: Assign custom values for `storage_gb`, `users`, and `api_calls` as negotiated in the contract.

## 2. Onboarding Flows

### A. The "White-Glove" Setup
1.  Admin creates the Tenant workspace manually via the Admin Portal.
2.  The "Owner" account is generated and credentials are sent securely.
3.  Sales Manager walkthrough of the **My Workspace** and **Custom Templates** modules.

### B. Self-Serve to Enterprise Conversion
1.  Prospect signups via the standard flow (assigned to **Trailing** or **Starter**).
2.  Sales team negotiates the upgrade.
3.  Admin manually switches the Tenant's plan to the new **Private Enterprise** package.
4.  Limits are updated instantly across all filters.

## 3. Post-Onboarding Monitoring
Account managers should use the **SA Analytics** dashboard to track Enterprise health:
- **Active Users**: Are they actually seats being utilized?
- **MRR (Monthly Recurring Revenue)**: Verification of subscription cycles.
- **Audit Logs**: High-level activity checks to ensure the client is deriving value.

## 4. Key Selling Points for Enterprise
- **Data Isolation**: Explain the `TenantScope` and dedicated storage directories.
- **AI Efficiency**: Focus on the ROI of AI-assisted UBL invoicing and Workspace search.
- **Compliance**: European e-invoicing (UBL) standards are metadata-baked.
