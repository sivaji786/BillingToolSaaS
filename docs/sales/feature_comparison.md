## Upsell Triggers
Sales representatives should monitor the following usage behaviors to trigger upgrade conversations:

1.  **80% Storage Utilization**: The tenant is actively using the "My Workspace" module and needs higher capacity.
2.  **User Limit Reached**: The team is growing and needs additional seats.
3.  **Multiple API Call Failures**: High engagement with AI features; prospect is a candidate for the **Pro** or **Enterprise** tier.
