## 3. Key Achievements (Apr 6–11, 2026)

### 🔐 Auth Hardening
- **Password Reset**: Full end-to-end forgot password flow — email submission, token-based link, secure reset screen with show/hide toggle.
- **DB Migration**: `password_resets` table (email, token, created_at) created via dedicated migration.
- **Public Route**: `UnifiedAuthFilter` excludes `/reset-password` from authentication checks.

### 🧾 Invoice Intelligence
- **Configurable Number Format**: Tenants define their numbering pattern using `{YYYY}`, `{YY}`, `{NNN...}`. Default: `INV-{YYYY}-{NNNNN}`.
- **Invoice Defaults**: Company profile stores `default_currency` (EUR), `default_tax_rate` (19.00%), `payment_terms_days` (30).
- **Auto-Numbering Utility**: `generateInvoiceNumber(format, currentCount)` replaces manual numbering.

### 🛒 Buyers Management
- Column sorting (name, email, company, address) with asc/desc toggle.
- Client-side address filter for large buyer directories.

### ⚙️ Settings UX
- New "Invoice Defaults" section: Default Currency, Tax Rate, Invoice Number Format, Payment Terms.
