## 🔧 How It Works

### **Before (Problem):**

## 📋 Installation Flow

```
1. User builds locally:
   npm run build
   → Creates generic build (no hardcoded URLs)

2. User packages:
   ./create-deployment-package.sh
   → Creates billingtool.zip

3. User uploads:
   - billingtool.zip
   - installer.php

4. User runs installer:
   https://yourdomain.com/installer.php
   → Fills in form with domain

5. Installer creates config.js:
   window.APP_CONFIG = {
     API_BASE_URL: 'https://yourdomain.com/api/public/index.php'
   };

6. Browser loads page:
   <script src="/config.js"></script>  ← Loads first
   <script src="/app.js"></script>      ← Then app

7. App uses correct URL:
   API calls → https://yourdomain.com/api/public/index.php ✅
```

---

## 🎯 Key Features

### **1. Build Once, Deploy Anywhere**
- Same build works on localhost, staging, production
- No need to rebuild for different environments

### **2. Automatic Configuration**
- Installer handles everything
- User just fills in their domain

### **3. Priority System**
```typescript
1. window.APP_CONFIG.API_BASE_URL  // Installer (production)
   ↓
2. import.meta.env.VITE_API_BASE_URL  // Build time (development)
   ↓
3. 'http://localhost:8080'  // Fallback
```
