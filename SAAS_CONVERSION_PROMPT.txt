## PHASE 1: MULTI-TENANCY ARCHITECTURE

### Database Schema Updates

1. Create new tables for multi-tenancy:
   - `tenants` table (id, company_name, subdomain, custom_domain, plan_id, status, trial_ends_at, created_at, updated_at)
   - `subscriptions` table (id, tenant_id, plan_id, stripe_subscription_id, status, current_period_start, current_period_end, cancel_at_period_end)
   - `plans` table (id, name, slug, price, billing_period, features JSON, limits JSON, is_active)

2. Add `tenant_id` foreign key to ALL existing tables:
   - invoices, templates, users, settings, activity_logs, etc.

3. Create migration files in `api/app/Database/Migrations/`

4. Create seeders for default plans (Starter €19, Professional €49, Business €99, Enterprise €299)

### Tenant Middleware & Isolation

1. Create `api/app/Filters/TenantFilter.php`:
   - Extract subdomain from request host
   - Query tenants table to find matching tenant
   - Set tenant in global config/context
   - Return 404 if tenant not found

2. Create `api/app/Traits/TenantScope.php`:
   - Add `beforeFind()` method to auto-filter by tenant_id
   - Add `beforeInsert()` to auto-add tenant_id
   - Prevent cross-tenant data access

3. Update `api/app/Models/BaseModel.php` to use TenantScope trait

4. Apply TenantFilter to all API routes in `api/app/Config/Filters.php`

5. Update ALL existing models to extend the new BaseModel

### Code Examples

```php
// api/app/Filters/TenantFilter.php
namespace App\Filters;

use CodeIgniter\Filters\FilterInterface;
use CodeIgniter\HTTP\RequestInterface;
use CodeIgniter\HTTP\ResponseInterface;
use App\Models\TenantModel;

class TenantFilter implements FilterInterface {
    public function before(RequestInterface $request, $arguments = null) {
        $host = $request->getUri()->getHost();
        $parts = explode('.', $host);
        
        // Extract subdomain (e.g., "acme" from "acme.billingtool.com")
        if (count($parts) >= 3) {
            $subdomain = $parts[0];
        } else {
            return Services::response()->setJSON(['error' => 'Invalid domain'])->setStatusCode(400);
        }
        
        $tenantModel = new TenantModel();
        $tenant = $tenantModel->where('subdomain', $subdomain)->where('status', 'active')->first();
        
        if (!$tenant) {
            return Services::response()->setJSON(['error' => 'Tenant not found'])->setStatusCode(404);
        }
        
        // Store tenant in request attribute
        $request->tenant = $tenant;
        
        // Also store in config for global access
        config('App')->currentTenant = $tenant;
    }
    
    public function after(RequestInterface $request, ResponseInterface $response, $arguments = null) {
        // Nothing needed
    }
}

// api/app/Traits/TenantScope.php
namespace App\Traits;

trait TenantScope {
    protected function beforeFind(array $data) {
        $tenant = config('App')->currentTenant;
        if ($tenant && !isset($data['data']['tenant_id'])) {
            $this->where('tenant_id', $tenant['id']);
        }
        return $data;
    }
    
    protected function beforeInsert(array $data) {
        $tenant = config('App')->currentTenant;
        if ($tenant && !isset($data['data']['tenant_id'])) {
            $data['data']['tenant_id'] = $tenant['id'];
        }
        return $data;
    }
}
```

## CODING STANDARDS

### Backend (PHP/CodeIgniter)

```php
// Always use tenant scope
class InvoiceModel extends BaseModel {
    use TenantScope;
    
    protected $table = 'invoices';
    protected $allowedFields = ['tenant_id', 'invoice_number', ...];
}

// Always validate tenant access
public function getInvoice($id) {
    $invoice = $this->invoiceModel->find($id);
    
    if (!$invoice || $invoice['tenant_id'] !== $this->tenant['id']) {
        return $this->failNotFound('Invoice not found');
    }
    
    return $this->respond($invoice);
}
```

### Frontend (React/TypeScript)

```typescript
// Always use tenant context
const { tenant, subscription, canCreateInvoice } = useTenant();

// Check limits before actions
const handleCreateInvoice = () => {
    if (!canCreateInvoice) {
        showUpgradePrompt();
        return;
    }
    // Proceed with creation
};

// Handle 402 Payment Required
api.interceptors.response.use(
    response => response,
    error => {
        if (error.response?.status === 402) {
            showUpgradeModal(error.response.data.upgradeUrl);
        }
        return Promise.reject(error);
    }
);
```
