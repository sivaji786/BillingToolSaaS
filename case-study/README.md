## 📊 Project Overview

**BillingTool** is a comprehensive invoice management system featuring:

- ✅ **EN 16931 Compliance** - European e-invoicing standard
- 🌍 **Multilingual Support** - 6 languages with RTL support
- 📤 **Multi-Format Export** - PDF, UBL XML, JSON, CSV
- 🎨 **Customizable Templates** - Branding and theming
- ♿ **WCAG 2.1 AA Compliant** - Full accessibility
- 🚀 **Modern Tech Stack** - React 18, TypeScript, CodeIgniter 4

## 🏗️ Technology Stack

**Frontend:** React 18 + TypeScript + Tailwind CSS v4.0  
**Backend:** CodeIgniter 4 + PHP 8.1+  
**Standards:** EN 16931, UBL 2.1, WCAG 2.1 AA

## 📈 Key Metrics

- **6 Languages** supported with full RTL
- **4 Export Formats** (PDF, UBL XML, JSON, CSV)
- **WCAG 2.1 AA** accessibility compliance
- **100% EN 16931** standard compliance
- **Real-time Validation** and calculations
